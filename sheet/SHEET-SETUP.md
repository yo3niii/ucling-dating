# 구글 시트 자동수집 셋업 (5분, 1회만)

우클링 하루연애 신청을 **구글 시트에 자동으로 쌓이게** 하는 설정.
Web3Forms 이메일은 그대로 유지되고(즉시 알림 백업), 시트가 관리용 원본이 된다.
전부 **무료**(구글 계정만 있으면 됨). 새 서버·DB 안 만든다.

---

## 1. 시트 만들기

1. 브라우저에서 **`sheets.new`** 접속 → 빈 스프레드시트 생성.
2. 이름을 **"우클링 하루연애 신청"** 으로 바꾼다.

## 2. Apps Script 붙여넣기

3. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭.
4. 편집기에 기본으로 있는 `Code.gs` 내용을 **전부 지우고**, 이 폴더의 **`Code.gs`** 파일 내용을
   **통째로 복사해서 붙여넣기**.
5. 💾 저장(Ctrl/Cmd+S).

## 3. 웹 앱으로 배포

6. 우측 상단 **배포 → 새 배포**.
7. 톱니바퀴(유형 선택) → **웹 앱** 선택.
8. 설정:
   - 설명: 아무거나 (예: v1)
   - **실행: 나(your@gmail)**
   - **액세스 권한: 모든 사용자**  ← 반드시 "모든 사용자"
9. **배포** 클릭 → 처음이면 권한 승인 팝업이 뜬다 → 본인 계정 선택 →
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음) 이동** → 허용.
   (내 계정 안에서 내가 만든 스크립트라 안전하다.)
10. 배포 완료 화면의 **웹 앱 URL** 복사. `.../exec` 로 끝난다.

## 4. 사이트에 URL 연결

11. `app.js` 맨 위 `CONFIG` 안의 `SHEET_ENDPOINT: ""` 에 방금 복사한 URL 을 붙여넣는다:
    ```js
    SHEET_ENDPOINT: "https://script.google.com/macros/s/AKfycb.../exec",
    ```
12. 저장 → 커밋/배포(Vercel)하면 이제부터 신청이 시트에 자동으로 쌓인다.

---

## 5. 동작 확인

- 실제 브라우저로 사이트 폼을 한 번 제출해본다.
  (⚠️ Web3Forms 무료 플랜은 브라우저 제출만 됨 — curl 테스트는 항상 실패한다.)
- 시트에 헤더 한 줄 + 방금 신청이 한 줄 쌓이면 성공.
- 이메일도 여전히 오는지 같이 확인.

컬럼 순서(자동 생성됨):
`타임스탬프 · 회차 · 닉네임 · 나이 · 성별 · MBTI · 관심클래스 · 활동지역 · 예산 · 시간대 · 내취향 · 원하는상대 · 연락처 · 인스타 · 개인정보동의 · 후기동의`

---

## 6. 기존 신청자 옮기기 (이미 이메일로 받은 몇 명)

**방법 A — 손으로 (가장 확실, 몇 명이면 추천)**
- 시트 헤더는 위에서 자동 생성됨. 이메일 내용을 보고 각 줄에 순서대로 붙여넣는다.

**방법 B — Gmail 자동 백필 (선택)**
- Apps Script 편집기 상단 함수 목록에서 **`backfillFromGmail`** 선택 → **실행**.
- 제목이 `[우클링 하루연애]` 인 메일을 찾아 시트에 자동으로 넣는다.
- ⚠️ 이메일 본문 포맷에 의존하는 자동 파서라 값이 어긋날 수 있다. **실행 후 시트를 꼭 눈으로
  확인**하고, 이상한 칸은 손으로 고친다. (몇 명뿐이면 방법 A가 더 빠를 수 있음.)

---

## 회차 바뀌면?

- `app.js` 의 `CONFIG.ROUND` 숫자만 바꾸면 시트 `회차` 칸에도 자동 반영된다.
- 링크가 고정이라 모든 회차 신청이 같은 시트에 쌓인다 → `회차` 칸으로 필터해서 구분한다.
