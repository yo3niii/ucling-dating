# 릴스 제작 규격 (우클링 하루연애)

우클링 하루연애 인스타 릴스를 만드는 공통 기준. 스크립트라이터·스토리보드디렉터·QA·메인 세션이 이 파일을 근거로 삼는다.

## 공통 영상 규격 (모든 편 필수)

| 항목 | 값 | 이유 |
|---|---|---|
| 비율/해상도 | **9:16 · 1080×1920** | 릴스·스토리·메타 광고 세로 |
| 길이 | **7~15초, 무한 루프** | 짧을수록 완주율↑ → 알고리즘·CPA 유리 |
| 훅 | **첫 1.5~2초에 승부** | 스크롤 멈추는 한 문장을 화면 꽉 채워서 |
| 자막 | **항상 자막 내장(무음 시청 전제)** | 릴스 대다수 소리 끄고 봄 |
| 마무리 | **"신청은 프로필 링크에서" CTA** | 모든 채널을 우클링 신청으로 수렴 |
| 폰트 | 픽셀편 Galmuri, 실사편 굵은 산세리프 자막 | 픽셀은 카드뉴스와 톤 일치 |
| 색 | 브랜드 토큰만. **핑크 하트는 화면당 1곳**, 본문은 plum | `brand/DESIGN-SYSTEM.md` |
| 프레임레이트 | 30fps 권장 | |

## 브랜드 토큰 (핵심)
- rose `#e0356b` (Primary·강조·CTA 버튼) / rose-deep `#b82a58`
- pink `#ff4d85` (**Accent = 하트·마음 액션, 화면당 1곳만**)
- blush `#ffedf2` (배경) / blush-deep `#ffdce8` / cream `#fff7f9`
- plum `#2b1b24` (본문 텍스트) / plum-mute `#7a6570` (보조)
- **rose를 본문 텍스트 색으로 쓰지 않는다**(대비 미달). 로즈 버튼 흰 라벨은 굵게 크게.
- 로고: `brand/` 에셋, 최소 32px, 변형·회전·그림자 금지.

## 5톤 광고 테스트 매핑 (기획서 5️⃣)
메타 광고는 톤이 다른 소재를 소액 동시 집행 → 신청 단가(CPA) 최저 승자에 예산 몰기.

| 톤 | 슬러그 | 성격 | 제작 방식 |
|---|---|---|---|
| 감성형 | `emotional` | "나도 연프…" 로망·설렘 | **픽셀 코드 파이프라인** + 마스코트 클리 |
| 유머형 | `humor` | "소개팅 망해도 머그컵은 남는다" 밈 | **실사 스톡 + ffmpeg** |
| 후기증언형 | `review` | "3:3 갔다가 진짜 연결됨" | 1회차 후 실사·캡처(현재 보류) |
| "나도 연프?" | `variety` | 연프 예능 자막 패러디 | 실사(현재 보류) |
| 클래스비주얼 | `visual` | 향초·도자기 결과물 클로즈업 | 실사 스톡(사장님 촬영 확보 시) |

## 제작 도구 (전부 무료)
- **Playwright**(이미 `insta/node_modules`): 픽셀편 HTML 프레임 캡처.
- **ffmpeg**(로컬 설치됨): 프레임→mp4, 트림·이어붙이기, drawtext 자막, 반반 split(hstack/overlay), BGM mux, 9:16 스케일/크롭.
- **claude-in-chrome MCP**(무료): 스톡 다운로드, 웹페이지 화면 녹화.
- **gemini-3-pro-imagegen 스킬**: 마스코트·인서트 스틸 생성. 전제 = Google AI Studio 무료 API 키(`GEMINI_API_KEY`). 소비자 Gemini 프로 구독과 별개. 키 없으면 SVG 코드 드로잉 폴백.
- Figma MCP는 무료 플랜 API 제약으로 릴스에 쓰지 않는다. CapCut은 자동화 API 없음 → ffmpeg로 대체(담당자 수동 편집 시 브리프 인수인계).

## 무료 스톡 라이선스
- Pexels / Mixkit: 무료·상업적 사용 가능·출처표기 불필요.
- **주의**: 스톡 인물을 "실제로 차였다/모욕당했다"는 식으로 defamatory하게 연출 금지. 부정 상황(거절 등)은 우리 자체 자산(예: `insta/망한소개팅/` 카톡 캡처)으로만, 스톡 인물은 일반적 감정·일상 장면으로만.

## 전환 추적 (메타 픽셀)
- 영상은 광고 소재일 뿐. 링크 클릭 → 기존 신청 페이지(`index.html`)의 메타 픽셀 `Lead` 이벤트로 이어진다(기존 로직 그대로, 영상이 새로 심을 것 없음).
- 링크는 고정 → 픽셀 데이터 누적 → 회차 거듭할수록 최적화 유리.

## 회차 운영
- 날짜·시간은 미리 확정 안 함. 영상 CTA/자막의 회차 표기(예: "N회차 모집 중")는 회차 바뀌면 소스에서 수동 수정 후 재렌더.
